# NeuroScan - AI Brain Tumour Detection

EfficientNetB0-based MRI classifier. Detects Glioma, Meningioma, Pituitary Adenoma, and No Tumor.

- Val Accuracy: 97.02%
- Test Accuracy: 93.48%
- Trained on 13,305 MRI scans (Kaggle + Mendeley)
